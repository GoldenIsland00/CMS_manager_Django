# سیستم مدیریت محصولات (CMS) دوزبانه با Django

یک سایت معرفی و کاتالوگ محصولات، حرفه‌ای، دوزبانه (فارسی/انگلیسی)، با پنل مدیریت کامل، آپلود چندگانه‌ی تصویر برای هر محصول، تولید خودکار QR Code برای فروشگاه، و قابلیت تغییر تم روشن/تاریک.

## امکانات

- **مدیریت محصولات از پنل ادمین جنگو**: دسته‌بندی، نام، توضیح کوتاه، توضیح کامل، قیمت، قیمت با تخفیف، موجودی، کد کالا (SKU)، مشخصات فنی (جدول key/value دلخواه).
- **آپلود چند عکس هم‌زمان**: از همان فرم افزودن/ویرایش محصول می‌توانید چند فایل را باهم انتخاب و آپلود کنید؛ اولین عکس به‌صورت خودکار «عکس اصلی» می‌شود. بعد از آپلود هم می‌توانید ترتیب، عکس اصلی بودن و حذفِ تک‌تک عکس‌ها را در همان صفحه مدیریت کنید.
- **QR Code خودکار برای فروشگاه**: در بخش «تنظیمات فروشگاه» در ادمین، آدرس سایت را وارد کنید؛ یک QR Code به‌صورت خودکار ساخته می‌شود (در فوتر همه‌ی صفحات هم نمایش داده می‌شود) که مشتری با اسکن آن مستقیم به سایت می‌رود.
- **دوزبانه (فارسی/انگلیسی)**: تمام محصولات و دسته‌ها فیلدهای جدا برای فارسی و انگلیسی دارند. آدرس‌ها به‌صورت `/fa/...` و `/en/...` هستند و یک سوییچ زبان در هدر سایت وجود دارد. جهت صفحه (RTL/LTR) به‌صورت خودکار عوض می‌شود.
- **تم روشن/تاریک**: دکمه‌ی تغییر تم در هدر، انتخاب کاربر را در یک کوکی ذخیره می‌کند (بدون نیاز به جاوااسکریپت، کار می‌کند).
- **صفحه‌ی محصول حرفه‌ای**: گالری تصاویر (تصویر اصلی + بندانگشتی‌های قابل کلیک)، قیمت با نمایش تخفیف، وضعیت موجودی، جدول مشخصات فنی، توضیحات کامل، محصولات مرتبط — شبیه ساختار فروشگاه‌های آنلاین حرفه‌ای.
- **دسته‌بندی و جستجو**: صفحه‌ی هر دسته با سایدبار دسته‌ها، مرتب‌سازی بر اساس قیمت/جدیدترین، صفحه‌بندی (pagination)، و جستجوی محصولات.

## پیش‌نیازها

- Python 3.10 یا بالاتر
- سیستم‌عامل با ابزار `gettext` نصب‌شده (برای کار درست ترجمه‌ها؛ روی اکثر توزیع‌های لینوکس با `apt install gettext` نصب می‌شود)

## نصب و راه‌اندازی

```bash
# ۱. ساخت محیط مجازی (اختیاری ولی توصیه‌شده)
python3 -m venv venv
source venv/bin/activate        # ویندوز: venv\Scripts\activate

# ۲. نصب پکیج‌ها
pip install -r requirements.txt

# ۳. اجرای مایگریشن‌ها (ساخت دیتابیس)
python manage.py migrate

# ۴. کامپایل فایل‌های ترجمه (فارسی)
python manage.py compilemessages

# ۵. ساخت حساب مدیر
python manage.py createsuperuser

# ۶. اجرای سرور توسعه
python manage.py runserver
```

سپس:
- سایت: http://127.0.0.1:8000/fa/  (یا `/en/` برای انگلیسی)
- پنل مدیریت: http://127.0.0.1:8000/fa/admin/

## اولین قدم‌ها بعد از نصب

1. وارد پنل ادمین شوید و از بخش **Store settings / تنظیمات فروشگاه** نام فروشگاه، شعار، لوگو، شماره تماس و مهم‌تر از همه **آدرس سایت (Store URL)** را وارد و ذخیره کنید — QR Code به‌صورت خودکار ساخته می‌شود.
2. از بخش **Categories / دسته‌بندی‌ها** چند دسته بسازید (مثلاً «لباسشویی»، «ظرفشویی»...).
3. از بخش **Products / محصولات** محصول جدید اضافه کنید:
   - نام، توضیح کوتاه و کامل را به هر دو زبان وارد کنید.
   - قیمت و در صورت نیاز قیمت با تخفیف را وارد کنید.
   - در بخش «Upload images / آپلود تصاویر» چند عکس را هم‌زمان انتخاب کنید.
   - بعد از ذخیره، از بخش «Specifications / مشخصات فنی» ردیف‌های مشخصات (مثل وزن، حجم، کشور سازنده) اضافه کنید.

## ساختار پروژه

```
shop_cms/
├── manage.py
├── requirements.txt
├── shop_cms/          # تنظیمات و URLهای اصلی پروژه
├── core/               # تنظیمات فروشگاه، QR Code، تم روشن/تاریک، صفحه‌ی اصلی
├── products/           # دسته‌بندی، محصول، تصاویر، مشخصات فنی
├── templates/          # قالب‌های HTML (base, home, category, product detail)
├── static/             # CSS و JS
└── locale/             # فایل‌های ترجمه فارسی/انگلیسی
```

## نکات مهم قبل از انتقال به سرور واقعی (Production)

فایل `shop_cms/settings.py` برای توسعه (development) تنظیم شده. پیش از انتشار روی سرور واقعی:

1. `SECRET_KEY` را با یک مقدار تصادفی و امن جایگزین کنید (هرگز مقدار پیش‌فرض را نگه ندارید).
2. `DEBUG = False` قرار دهید.
3. `ALLOWED_HOSTS` را به دامنه‌ی واقعی سایت محدود کنید (مثلاً `["example.com", "www.example.com"]`).
4. برای دیتابیس واقعی بهتر است از PostgreSQL یا MySQL به‌جای SQLite استفاده کنید.
5. فایل‌های استاتیک را با `python manage.py collectstatic` جمع‌آوری و روی وب‌سرور (Nginx و مانند آن) سرو کنید.
6. سایت را پشت HTTPS قرار دهید.

## افزودن زبان یا متن جدید

اگر متن ثابت جدیدی به قالب‌ها اضافه کردید (با تگ `{% trans "..." %}`)، برای این‌که ترجمه‌ی فارسی آن هم اعمال شود:

```bash
python manage.py makemessages -l fa
# سپس رشته‌ی ترجمه را در locale/fa/LC_MESSAGES/django.po وارد کنید
python manage.py compilemessages
```
